# praktikum-vcs-pti

**Latihan Version Control Sistem Mahasiswa PTI**

## Deskripsi Proyek
Repository ini dibuat untuk memenuhi tugas praktikum Version Control System (VCS) mahasiswa Pendidikan Teknologi Informasi (PTI). Praktikum ini bertujuan untuk mempelajari penggunaan GitHub sebagai platform untuk menyimpan, mengelola, dan mendokumentasikan proyek secara online.

## Tujuan Praktikum
- Memahami cara membuat repository di GitHub.
- Memahami pengaturan visibilitas repository Public dan Private.
- Membuat dan mengedit file README.md.
- Mempelajari cara menyimpan perubahan menggunakan fitur commit.

## Hasil Praktikum
Repository berhasil dibuat dengan file README.md yang berisi deskripsi proyek dan riwayat commit sebagai bukti penyimpanan perubahan.

## Kesimpulan
Melalui praktikum ini, mahasiswa dapat memahami dasar penggunaan GitHub untuk mengelola proyek dan menyimpan perubahan secara terstruktur.
